BENCH TEST

How to measure a cheap AM transmitter before connecting an antenna

Published September 27, 2026 · Resonance Radio

Before asking how far a transmitter reaches, establish what it is actually doing electrically.

Minimum useful equipment

  • Digital multimeter.
  • Known resistive dummy load appropriate for the RF stage.
  • Oscilloscope if available.
  • Low-cost SDR receiver for spectrum checks.

Measure DC input to the final stage

For a §15.219-oriented design, the relevant limit is the DC input power to the final RF stage, not a seller's claimed RF output. If the final stage can be isolated electrically, measure its supply voltage and current and calculate P = V × I.

Check the carrier

With no modulation, verify carrier frequency and stability after warm-up. Note any drift over ten to thirty minutes. With audio applied, inspect the envelope for obvious over-modulation or clipping.

Look beyond the carrier

An SDR spectrum is useful for spotting harmonics, spurs and unexpected oscillation. Absolute SDR amplitude may be poorly calibrated, but relative changes are still valuable if gain settings and geometry are fixed.

For a repeatable conducted sample, see the low-cost RF sampler/attenuator build.

Safety margin

Run conservatively during characterization. Do not assume a potentiometer marking or software setting corresponds directly to legal final-stage input power.

Publish the raw setup

A useful review should state the supply, load, SDR gain, distance and antenna configuration. That lets another builder reproduce the test instead of relying on a single “range” number.

What a useful test table looks like

For each operating point, record carrier frequency, transmitter supply voltage, final-stage voltage, final-stage current, audio source level, dummy-load value and SDR gain. Add notes about waveform clipping and device temperature. If you later change the supply or antenna tuner, repeat the same table instead of relying on memory. This is enough structure to turn a cheap-module experiment into a comparison another builder can reproduce.
