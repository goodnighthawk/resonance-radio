# Resonance Radio public site

Static site for the Resonance Radio low-cost radio/electronics project.

## Local preview

```bash
cd ~/resonance-radio-site
python3 -m http.server 8088
```

Then open http://127.0.0.1:8088/

## Publish

Intended repository: `goodnighthawk/resonance-radio`

After the GitHub repository exists, push the contents of this folder to `main` and enable GitHub Pages from the repository root. Once an Amazon Associates tracking ID is approved, replace ordinary Amazon product URLs with official tagged links and update the affiliate disclosure to the required Amazon wording.
